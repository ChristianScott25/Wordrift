# Words the game REFUSES even though the imported lexicon has them.
#
# The main list is a 2006 Scrabble tournament lexicon. It predates the 2020
# removal of slurs from tournament word lists, so it contains them and would
# happily score them. This file takes them back out.
#
# It is applied LAST, after wordlist.txt and wordlist-extra.txt, so a word here
# is refused no matter what any other list says. Blocked always wins.
#
# Rules:
#   - one lowercase word per line, a-z only, alphabetical
#   - lines starting with # are comments, blank lines are ignored
#   - EVERY INFLECTION NEEDS ITS OWN LINE. The lexicon carries all of them
#     (shit/shits/shitted/shitting/shitty), and blocking only the root leaves
#     the rest playable. This is the mistake to check for after any edit.
#   - do NOT add a word whose ordinary meaning is innocent. These were all
#     checked against collisions and deliberately left playable: spice, spicy,
#     spike, spiky, jape, mingy, darkish, niggle, niggard, pollack, dike,
#     dwarf, pygmy, scrotum, hell, damn.
#
# The borderline cases were decided by hand on 2026-09-08, in four groups:
# words that are both a slur and an ordinary word (blocked), vulgar words whose
# innocent sense still dominates (kept: prick, tit, boob, slag, shag, spunk,
# snatch, hooker, bastard), historical clinical terms (pure slurs blocked,
# ordinary insults like idiot and moron kept), and contested identity terms
# (slurs blocked, 'queer' and 'gypsy' kept as current usage).
#
# Two entries here are worth a second look, because their offensive sense is
# NOT the obvious one: 'sheeny' also means shiny, and 'greaser' also means one
# who greases. Both were blocked deliberately. Delete the line to undo.
